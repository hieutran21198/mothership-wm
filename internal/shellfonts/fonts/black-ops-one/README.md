# Black Ops One

Vendored regular face, version 1.004, from
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/blackopsone).
The font ships with its SIL Open Font License in `OFL.txt`. Pango registers
it in the Panel and window manager's private font maps, not in system settings.

SHA-256: `282a825b5f294377387e3969f765408157dbea8da0f5d0aae68c6bc704b145b3`.
