# Capture a screenshot

The desktop user needs to copy or save a precise image of their Mothership
session so they can share what they see without cropping it in another app.

| Criterion | Observable success | Proven by |
| --- | --- | --- |
| Select | Choose Area, Window, or Display and see which pixels the capture will cover. | [Selection](../flows/capture-screenshot.md#selection) |
| Deliver | Paste the image into an app in the same session or save a PNG to Screenshots. | [Export](../flows/capture-screenshot.md#export) |
| Return | Finish or cancel and resume input in the previous app or shell view. Recover from a failed export. | [Recovery](../flows/capture-screenshot.md#recovery) |
