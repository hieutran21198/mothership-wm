# Find and launch installed apps from App Grid

A user on Home or in a Node needs quick access to pinned apps and a way to
browse and launch any app in the available catalog.

| Criterion | Observable success | Proven by |
| --- | --- | --- |
| Browse the catalog | Each open starts with installed pins when present. The user can reach every page by mouse or keyboard, including when no pins exist. | [Browse pages](../flows/use-app-grid.md#scenarios) |
| Find a specific app | The user can edit a query and find an app from any catalog page, then activate the matching tile. | [Search and launch](../flows/use-app-grid.md#scenarios) |
